# Notes-App
mini application to note your information

A simple and beginner-friendly Notes App built using HTML, CSS, and JavaScript.  
This app allows users to create, save, and delete notes easily.

---

## 🚀 Features

- ➕ Add new notes  
- 💾 Save notes in browser (Local Storage)  
- 🗑️ Delete notes  
- ✏️ Edit notes  
- 📱 Responsive design (works on mobile & desktop)  

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript
